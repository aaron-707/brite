# AI Usage

Disclosure of AI tooling used in this submission, as required by the Brite Spark
2026 participant handbook.

## Tools used

**Antigravity** — used throughout the project as an architectural sounding board and prompt engineering partner. Specific uses are listed below.

**Gemini Flash Lite Latest (Google)** — the runtime synthesis model (`gemini-flash-lite-latest`). Model selection required empirical testing across several Gemini model variants due to free-tier quota differences discovered during development, and this final locked model was chosen for its daily quota reliability and confirmed JSON-schema support. All pipeline outputs were generated by this model under the system prompt designed for this project.


## What Antigravity did

- Reviewed pipeline output from the first three test queries and identified two bugs: the `_CITE_RE` regex only matching three-digit citations (missing §5.4), and the numeric contradiction detector emitting duplicate conflict entries.
- Identified the root cause of the §7.1.3 → §7.3 gate false positive (structural connective phrase with no topical signal in preceding tokens).
- Designed the numeric contradiction detector redesign (same §-anchor + same unit required to flag, rejecting base-rule/exception pairs as contradictions).
- Proposed and iterated on the synthesizer system prompt — citation discipline, grounding rules, conflict handling format, and escalation instruction wording.
- Designed the stress test plan (edge cases, vocabulary mismatch, ugly phrasing, day-two corpus simulation) and wrote the test prompts.
- Identified that the query expansion problem required three fix attempts before reaching the correct design (reactive hardcoding → low-DF mapping → dynamic corpus-derived map).
- Designed the corpus fingerprint cache for the dynamic synonym map (MD5 hash comparison at startup).
- Co-designed and implemented the **Temporal Resolver** (`src/temporal.py`) to parse and resolve base/amended manual clause versions based on determination and event dates.
- Identified and fixed the **parser boundary chunking bug** in `src/parser.py` (flushing the active clause chunk when hitting `#` or `##` part/section headings).
- Co-designed the **Citation Validator hardening rules** to block adversarial exploits (filtering out clause ID digits, enforcing query digit constraints, restricting uncited validation fallback to contextual continuations of `last_cited_id`, and raising the continuation threshold to `0.35`).
- Implemented the **pipeline escalation-phrase post-processing safeguard** to clean up minor synthesizer paraphrasing drift on conflict responses.
- Operated as an active agent on the workspace filesystem, executing commands, running evaluation/test suites, editing files, and creating Git commits under human supervision and review at each step.
- Drafted `DECISIONS.md` sections for review and editing.

## What AI did not do

- Did not operate completely autonomously without human review and direction — every command execution, test run, file edit, and Git commit was explicitly requested, monitored, and approved.
- Did not make any final architectural decisions — every design, pattern, and modification was reviewed and approved.
- Did not select which problem to attempt or which overall architectural approach to take.
