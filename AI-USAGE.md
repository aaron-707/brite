# AI Usage

This file discloses how AI tooling was used in building this submission,
as required by the Brite Spark 2026 participant handbook.

## Tools used

- **Antigravity (Google DeepMind)** — used throughout the project for architectural
  guidance, prompt engineering for the synthesizer system prompt, debugging
  the citation validator regex, designing the gate's structural connective
  whitelist, redesigning the numeric contradiction detector, implementing the 
  query expansion retriever fix, and drafting the evaluation question set.

- **Gemini 3.5 Flash / 3.5 Flash Lite / 3.6 Flash (Google)** — used as the synthesis
  models at runtime. All pipeline outputs in the evaluation results were
  generated by these models under the system prompt designed for this project.

## What AI did

- Proposed and iterated on the synthesizer system prompt (grounding rules,
  citation discipline, conflict handling, escalation instruction format).
- Identified the root cause of the citation validator false negative
  (_CITE_RE only matching 3-digit §-citations, missing §5.4).
- Identified the root cause of the gate false positive (§7.1.3 → §7.3
  flagged as dead reference due to structural connective phrase).
- Designed the numeric contradiction detector redesign (same §-anchor +
  same unit required to flag).
- Suggested the query expansion approach for vocabulary mismatch between
  user queries and manual terminology.
- Drafted DECISIONS.md sections and README.md updates for review.

## What I did

- Designed and implemented the corpus parser, BM25 retriever, TF-IDF
  retriever, RRF fusion, gate, and pipeline architecture.
- Made all final decisions on what to accept, reject, or modify from
  AI suggestions.
- Wrote and ran all verification queries to confirm fixes before committing.
- Can explain every component of this submission and what it would do
  on an input not yet tested.

## What AI did not do

- AI did not write the retriever, gate, or pipeline code directly.
- AI did not select which problem to attempt.
- AI did not run the code or access the repository.
