## Tools used

**Antigravity** — used throughout the project as an architectural sounding board and prompt engineering partner. Specific uses are listed below.

**Gemini Flash Lite Latest (Google)** — the runtime synthesis model (`gemini-flash-lite-latest`). Model selection required empirical testing across several Gemini model variants due to free-tier quota differences discovered during development, and this final locked model was chosen for its daily quota reliability and confirmed JSON-schema support. All pipeline outputs were generated by this model under the system prompt designed for this project.


## What Antigravity did

- Reviewed pipeline output from the first three test queries and identified two bugs: the `_CITE_RE` regex only matching three-digit citations (missing §5.4), and the numeric contradiction detector emitting duplicate conflict entries.
- Identified the root cause of the §7.1.3 → §7.3 gate false positive (structural connective phrase with no topical signal in preceding tokens).
- Designed the numeric contradiction detector redesign (same §-anchor + same unit required to flag, rejecting base-rule/exception pairs as contradictions).
- Proposed and iterated on the synthesizer system prompt — citation discipline, grounding rules, conflict handling format, and escalation instruction wording. During iteration, an unrequested per-sentence citation rule was introduced mid-fix; testing found it caused a real double-citation regression on evaluation questions, and it was reverted with reasoning documented. This pattern recurred twice across the session — once for the original citation-discipline rule and once for a similar per-sentence proration citation instruction — both caught by eval re-runs and rolled back.
- Designed the stress test plan (edge cases, vocabulary mismatch, ugly phrasing, day-two corpus simulation) and wrote the test prompts.
- Identified that the query expansion problem required three fix attempts before reaching the correct design (reactive hardcoding → low-DF mapping → dynamic corpus-derived map).
- Designed the corpus fingerprint cache for the dynamic synonym map (MD5 hash comparison at startup).
- Co-designed and implemented the **Temporal Resolver** (`src/temporal.py`) to parse and resolve base/amended manual clause versions based on determination and event dates.
- Identified and fixed the **parser boundary chunking bug** in `src/parser.py` (flushing the active clause chunk when hitting `#` or `##` part/section headings).
- Co-designed the **Citation Validator hardening rules (round 1)** to block adversarial exploits: filtering out clause ID digits, enforcing query digit constraints, restricting uncited validation fallback to contextual continuations of `last_cited_id`, and raising the continuation threshold to `0.35`. These rules were found by constructing adversarial test sentences that initially passed verification incorrectly before the fix was applied.
- Co-designed **Citation Validator hardening (round 2)**: a conflict-commentary filter to skip structural meta-sentences (e.g. "there is a conflict", "inconsistent") from factual verification, and a refined digit-filter restricting query-digit exclusions to 4-digit year tokens only (e.g. `2026`), ensuring shorter query digits (e.g. `45` days) remain subject to strict verification. Found the same way — newly constructed adversarial sentences that bypassed round-1 rules.
- Implemented the **pipeline escalation-phrase post-processing safeguard** to clean up minor synthesizer paraphrasing drift on conflict responses.
- Implemented `_compute_prorated_rate()` as **pure deterministic date arithmetic** (not LLM-calculated) to compute day-weighted average rates for claim periods spanning the 1 March 2026 amendment boundary. This design avoids introducing new hallucination risk into spanning-claim answers — the prorated figure is a precomputed fact injected into context, the same way §5.3/§7.4.3 text is injected.
- Diagnosed a **real retrieval gap** where an adversarial query using "cars" failed to match the cached singular "car" synonym key, causing the system to falsely claim the manual didn't cover vehicle ownership when §2.4.2 explicitly does. Implemented a punctuation-stripping and singular-fallback normalization fix (`_get_singular_forms`) in query expansion, verified against a full 20-question eval re-run to confirm no regression.
- Operated as an active agent on the workspace filesystem, executing commands, running evaluation/test suites, editing files, and creating Git commits under human supervision and review at each step.
- Drafted `DECISIONS.md` sections for review and editing.
